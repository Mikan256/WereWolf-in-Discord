# WereWolf-in-Discord
Discord上で人狼をするためのbot

## 仕様書

Discordボットを使用してDiscord鯖上で自由に人狼をできるようにします。
人狼ゲームとは人狼陣営と市民陣営に分かれて行う試合です。(昼のターンと夜のターンに分かれて行います。)

コマンド

| /setting        | 対話形式で設定を決める。(ホストのみがいじれる)(すでに開始されている場合は使えない。)(引数なしで行った場合はbotとの対話形式(ボタンを押したり選択する)形で設定を決める。) |
| --------------- | ----------------------------------------------------------------------------------------- |
| /start          | ホストのみができる。設定がセットされているならゲームを開始する。(すでに開始されている場合は使えない。)                                      |
| /stop           | ホストのみができる。ゲームを強制終了し、初期化する。(試合中のみしか使えない。)                                                  |
| /skip           | ホストのみができる会議時間のスキップ。即投票時間にうつる。(会議時間中のみしかつかえない。)                                            |
| /end            | 試合終了したあとに初期化を行う。(試合終了後のみ使える。)                                                             |
| /setting-status | 自分がどういう設定をしたのかを確認する。                                                                      |
| /help           | コマンド一覧と説明を見る。また、役職ごとの説明も読むことができます。                                                        |

# 📜 ゲームモード一覧

このbotでは **通常人狼** と **ワンナイト人狼** の2つのゲームモードを選択できます。
`/setting` 内でゲームモードを切り替えます。

# モード1: 通常人狼（クラシックモード）

従来の複数日跨いで行う人狼ゲーム。

### 試合の流れ

※昼や夜のラウンド開始時にn日目の昼/夜です。とメッセージがゲーム用のテキストチャンネルに送られるようにする。
※試合中ボイチャのチャンネルやミュートなどは常に固定化されるようになる。
※死亡したプレイヤーは観戦者と同じようになる。
1. ホストする人が参加者、役職の割合、会議時間を決定する。
2. スタートと同時にゲーム用ボイスチャンネルとゲーム用のテキストチャンネルを作成して参加者のみアクセスできるようにする。(参加者はゲーム用ボイスチャンネルに移動させる)また、人狼陣営専用の人狼テキストチャンネルを作成する。そして、各個人に何の役職かのメッセージと立ち回りの説明をゲーム用テキストチャンネルで送る。なお、待機所ボイスチャンネルにいた人で参加者ではない人は観戦者として全て見れるようにする。(観戦者用テキストチャンネルを作り、そこに全ユーザーの役職などを送る)(ゲーム用のボイスチャンネルは常にミュートで参加)
3. まずは昼のターン(1日目昼)です。ゲーム用のテキストチャンネルにプレイヤー全員が書き込むことができるようになり、指定した会議時間ぶんの会議をします。(このときは追放の投票はしません。)(人狼陣営専用の人狼テキストチャンネルは誰もテキストを打てなくなる。)
4. 次は夜のターンです。誰もゲーム用のテキストチャンネルにテキストを打つことができなくなり、ゲーム用ボイスチャンネルの全員がミュートになります。また、人狼陣営専用のテキストチャンネルで人狼陣営がテキストを打つことができるようになる。そして夜にその役職専用のメッセージが前の役職の人の動作が終わったら来るようにし、それぞれ送られてきたメッセージのボタンを押して動作を行うことができる。(役職別の動作は後述)また、人狼が行う殺害は一番最後の動作となる。これら全てが終わったら次の日の昼となる。
5. 次は昼のターンです。最初に前日の夜に死亡した人を発表する。人狼陣営専用のテキストチャンネルはテキストを打てなくなり、プレイヤー全員のボイチャのミュートが解除されてゲーム用のテキストチャンネルに全員が文字を打てるようになる。そして会議時間が終了したら投票時間に入り、プレイヤー全員が投票するまで待つ。(誰を追放するかの投票)そして最も票が多かったものが死亡する。(同票の場合決選投票)
6. その後4~5を繰り返してそれぞれの陣営の勝利条件を先に満たしたところが勝利。勝利陣営が決まったら7へと進む。
7. ゲームのリザルト(勝利陣営がどれかとそれぞれのプレイヤーが何の役職であったかのネタバラシ)を行い/endをホストが行ったらゲームの初期化を行う。

※ゲームの初期化とは・・・ ゲーム用のテキストチャンネルと人狼陣営専用のテキストチャンネルおよびゲーム用のボイスチャンネルを削除して観戦者も含めて全員を待機所チャンネルに戻す。(設定はリセットしない。)

# モード2: ワンナイト人狼（ワンナイトモード）

## 概要

**ワンナイト人狼** は、通常の人狼とは違い **たった1回の夜と昼（1ラウンド）** で勝敗が決まる短時間決戦型の人狼ゲームです。

通常の人狼との主な違い:
- **1ラウンドのみ**: 夜→昼の1セットでゲーム終了。「翌日」は存在しない。
- **夜襲撃なし**: 人狼が夜に誰かを殺すことはできない。代わりに夜の間に役職カードが入れ替わる。
- **役職が動く**: 夜の間に占い師がカードを覗いたり、怪盗が役職を交換するなど、誰かの役職が変化する可能性がある。
- **センターカード**: 参加者数＋3枚の役職カードを使い、余った3枚は「センター（山札）」に置かれる。誰の役職でもないカードが存在するため、推理がより複雑になる。
- **議論と投票のみ**: 限られた情報と短い時間での推理力・話術が試される。
- **観戦者は不要**: ゲームが短いため、観戦者チャンネルは作成せず、全員参加を前提とする。

## ゲームの流れ

### セットアップ
1. ホストが `/setting` でゲームモードを「ワンナイト人狼」に設定する。
2. 参加者を選択し、使用する役職の内訳を設定する。
3. ホストが `/start` でゲームを開始する。

### ゲーム進行
4. **役職配布**: 全プレイヤー＋3枚の役職カードが用意される。各プレイヤーに1枚ずつランダムに配布され、余った3枚は「センターカード」として公開されずに置かれる。
   - 例: 5人プレイの場合、8枚の役職カードを用意 → 5人に配布 → 3枚がセンターに。
   - 各プレイヤーは自分の役職のみ確認できる。
   - 通常の人狼と違い、**人狼テキストチャンネルやボイスチャンネルの移動は行わない**（全員同じテキストチャンネルで行う）。

5. **夜フェーズ（約60秒）**: 以下の役職が順番に行動する。各役職の行動は個人にDMで送信され、ボタン操作で行う。
   - 行動は**順番に**行われ、前の役職の行動が完了してから次の役職のDMが送られる。
   
   **夜の行動順:**
   1. **人狼** - 互いを確認する（役職画面に表示）。アクション不要。
   2. **占い師** - 任意のプレイヤー1人の役職カードを見る **or** センターカード2枚を見る。
   3. **怪盗** - 任意のプレイヤー1人と役職カードを交換し、交換後の自分の役職を確認する。
   4. **トラブルメーカー** - 自分以外のプレイヤー2人を選び、その役職カードを交換する（中身は見ない）。
   5. **酔っ払い** - 自分の役職カードをセンターカードのいずれか1枚と交換する（中身は見ない）。
   6. **失眠症** - 最終的に自分の役職を確認する（自分が入れ替えられたかを知る）。

6. **昼フェーズ（会議: 設定時間）**: 全員が目を覚まし、テキストチャンネルで自由に議論を行う。
   - 自分が何だったか、夜に何をしたか（してもいいし、嘘をついてもいい）を話し合う。
   - 人狼は自分が人狼でないふりをするため、積極的に嘘の情報を流す。

7. **投票フェーズ**: 会議終了後、誰を追放するか投票する。
   - 最も票を集めたプレイヤーが追放される（同票の場合は誰も追放されない）。

8. **結果発表・勝敗判定**:
   - 追放されたプレイヤーの役職が公開される。
   - 全プレイヤーの最終的な役職が公開される（夜の入れ替わりを反映）。
   - 勝利条件を満たした陣営が勝利する。

### 勝利条件

| 陣営 | 勝利条件 |
|------|---------|
| **市民陣営** | 追放されたプレイヤーが人狼である（1人でも人狼が追放されれば市民陣営の勝利）。 |
| **人狼陣営** | 追放されたプレイヤーが人狼ではない（人狼が1人も追放されなければ人狼陣営の勝利）。 |
| **皮なめし職人** | 自分が追放される（単独勝利。他の陣営の勝敗を上書きする）。 |
| **狩人** | 通常は所属陣営の勝利条件に従う。追放された場合、自分を追放させたプレイヤーを1人道連れにする。 |

※人狼が複数いる場合でも、1人でも追放されれば市民陣営の勝利となる。
※誰も追放されなかった場合（同票など）は人狼陣営の勝利となる。

### ワンナイト人狼 役職リスト

| 役職名 | 陣営 | 夜のアクション | 説明 |
|--------|------|---------------|------|
| **市民** | 市民陣営 | なし | 特殊な能力はない。議論と投票での推理がすべて。 |
| **人狼** | 人狼陣営 | 互いを確認する | 他の人狼が誰かを知ることができる。自分が人狼であることを隠して議論をかく乱する。勝利条件: 自分（人狼）が追放されないこと。 |
| **占い師** | 市民陣営 | プレイヤー1人の役職を見る OR センターカード2枚を見る | 夜に誰かの正体を覗き見するか、センターのカードを確認できる。得た情報をどう使うかが鍵。 |
| **怪盗** | 市民陣営 | プレイヤー1人と役職を交換する | 指名したプレイヤーと役職を丸ごと交換する。交換後、自分が何になったかを確認できる。交換された相手は自分が交換されたことに気づかない（失眠症を除く）。 |
| **トラブルメーカー** | 市民陣営 | プレイヤー2人の役職を交換する | 自分以外の2人の役職を交換する。中身は見えない。誰と誰を交換したかで議論をかく乱できる。 |
| **酔っ払い** | 市民陣営 | 自分の役職をセンターと交換する | 自分の役職をセンターのいずれかと交換する。中身は見えない。自分が何になったか最後までわからない。 |
| **失眠症** | 市民陣営 | 最終的に自分の役職を確認する | 全員のアクションが終わった後、最後に自分の現在の役職を確認できる。自分が交換されたかどうかを知ることができる唯一の役職。 |
| **狩人** | 市民陣営 | なし | 投票で追放された場合、自分に投票したプレイヤーの中からランダムに1人道連れにする。道連れにされたプレイヤーも死亡する。 |
| **皮なめし職人** | 第三陣営 | なし | 自分が追放されると単独勝利する。それ以外の場合は敗北。追放されたくなければ、いかに自分の正体を隠して追放を回避するかが鍵。逆に追放されたい場合は怪しい行動をとる。 |

### 役職構成の推奨セット

ワンナイト人狼は役職のバランスが重要。以下は人数別の推奨セット:

**3〜5人用（基本セット）:**
- 人狼 ×2
- 占い師 ×1
- 怪盗 ×1
- トラブルメーカー ×1
- 市民 ×1〜3（人数に応じて調整）
- センターに余った3枚を配置

**5〜7人用（拡張セット）:**
- 人狼 ×2
- 占い師 ×1
- 怪盗 ×1
- トラブルメーカー ×1
- 酔っ払い ×1
- 失眠症 ×1
- 市民 ×2〜4
- センターに余った3枚を配置

**7〜9人用（フルセット）:**
- 人狼 ×2〜3
- 占い師 ×1
- 怪盗 ×1
- トラブルメーカー ×1
- 酔っ払い ×1
- 失眠症 ×1
- 狩人 ×1
- 皮なめし職人 ×1
- 市民 ×1〜4
- センターに余った3枚を配置

### 実装上の注意点

- **チャンネル管理**: 通常人狼とは異なり、ワンナイト人狼では複数のテキストチャンネルやボイスチャンネルは作成しない。既存のテキストチャンネル1つで全ての進行を行う。
- **夜アクションのDM送信**: 各プレイヤーの夜アクションはDMで個別に送信され、ボタンで操作する。アクションは順番に行われる。
- **ボイスチャンネル**: ワンナイト人狼ではボイスチャンネルのミュート管理は行わない（短時間のため手動管理を推奨）。
- **時間設定**: 夜フェーズは約60秒（全員のアクション完了またはタイムアウトまで）。昼の会議時間は通常3〜5分推奨。
- **観戦者**: ゲーム時間が短いため、観戦者機能は実装しない。
- **ゲームモードの選択**: `/setting` の最初の選択肢で「通常人狼」か「ワンナイト人狼」を選べるようにする。選択肢に応じて設定可能な役職とゲームフローが変化する。
