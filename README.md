# WereWolf-in-Discord
Discord上で人狼をするためのbot

## 仕様書


Discordボットを使用してDiscord鯖上で自由に人狼をできるようにします。
人狼ゲームとは人狼陣営と市民陣営に分かれて行う試合です。(昼のターンと夜のターンに分かれて行います。)

コマンド

| /setting | 対話形式で設定を決める。(ホストのみがいじれる)(すでに開始されている場合は使えない。)         |
| -------- | ---------------------------------------------------- |
| /start   | ホストのみができる。設定がセットされているならゲームを開始する。(すでに開始されている場合は使えない。) |
| /stop    | ホストのみができる。ゲームを強制終了し、初期化する。(試合中のみしか使えない。)             |
| /skip    | ホストのみができる会議時間のスキップ。即投票時間にうつる。(会議時間中のみしかつかえない。)       |
| /end     | 試合終了したあとに初期化を行う。(試合終了後のみ使える。)                        |

### 試合の流れ

※昼や夜のラウンド開始時にn日目の昼/夜です。とメッセージがゲーム用のテキストチャンネルに送られるようにする。
※試合中ボイチャのチャンネルやミュートなどは常に固定化されるようになる。
※死亡したプレイヤーは観戦者と同じようになる。
1. ホストする人が参加者、役職の割合、会議時間を決定する。
2. スタートと同時にゲーム用ボイスチャンネルとゲーム用のテキストチャンネルを作成して参加者のみアクセスできるようにする。(参加者はゲーム用ボイスチャンネルに移動させる)また、人狼陣営専用の人狼テキストチャンネルを作成する。そして、各個人に何の役職かのメッセージと立ち回りの説明をゲーム用テキストチャンネルで送る。なお、待機所ボイスチャンネルにいた人で参加者ではない人は観戦者として全て見れるようにする。(観戦者用テキストチャンネルを作り、そこに全ユーザーの役職などを送る)(ゲーム用のボイスチャンネルは常にミュートで参加)
3. まずは昼のターン(1日目昼)です。ゲーム用のテキストチャンネルにプレイヤー全員が書き込むことができるようになり、指定した会議時間ぶんの会議をします。(このときは追放の投票はしません。)(人狼陣営専用の人狼テキストチャンネルは誰もテキストを打てなくなる。)
4. 次は夜のターンです。誰もゲーム用のテキストチャンネルにテキストを打つことができなくなり、ゲーム用ボイスチャンネルの全員がミュートになります。また、人狼陣営専用のテキストチャンネルで人狼陣営がテキストを打つことができるようになる。そして夜にその役職専用のメッセージが前の役職の人の動作が終わったら来るようにし、それぞれ送られてきたメッセージのボタンを押して動作を行うことができる。(役職別の動作は後述)また、人狼が行う殺害は一番最後の動作となる。これら全てが終わったら次の日の昼となる。
5. 次は昼のターンです。最初に前日の夜に死亡した人を発表する。人狼陣営専用のテキストチャンネルはテキストを打てなくなり、プレイヤー全員のボイチャのミュートが解除されてゲーム用のテキストチャンネルに全員が文字を打てるようになる。そして会議時間が終了したら投票時間に入り、プレイヤー全員が投票するまで待つ。(誰を追放するかの投票)そして最も票が多かったものが死亡する。(同票の場合決選投票)
6. その後4~5を繰り返してそれぞれの陣営の勝利条件を先に満たしたところが勝利。勝利陣営が決まったら7へと進む。
7. ゲームのリザルト(勝利陣営がどれかとそれぞれのプレイヤーが何の役職であったかのネタバラシ)を行い/endをホストが行ったらゲームの初期化を行う。

※ゲームの初期化とは・・・ ゲーム用のテキストチャンネルと人狼陣営専用のテキストチャンネルおよびゲーム用のボイスチャンネルを削除して観戦者も含めて全員を待機所チャンネルに戻す。(設定はリセットしない。)

| --- | ---- | ----------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| 市民  | 市民陣営 | 昼の時間にゲーム用のテキストチャンネルで会議をして投票を行う。                                                                             | 人狼陣営が全員死亡すること                                              |
| 人狼  | 人狼陣営 | 昼は議論の場をゲーム用のテキストチャンネルでかき乱し、夜に人狼用のテキストチャンネルで会議をして殺す市民を選ぶ。(なお人狼数にかかわらず一夜で殺せるのは一人まで。)また、役職を配られる際に他の誰が人狼なのかわかる。 | 市民陣営の数が人狼陣営の数の同数以下になること                                    |
| 共犯者 | 人狼陣営 | 昼に議論の場をゲーム用のテキストチャンネルでかき乱す。誰が人狼なのかを知ることはできるが、人狼からは誰が共犯者なのかはわからない。(人狼用のテキストチャンネルにはアクセスできない。)                 | 市民陣営の数が人狼陣営の数の同数以下になること                                    |
| 妖狐  | 第三陣営 | 人狼によって殺されるのに選ばれても死亡しないが、占われたり会議の投票によって死亡する。                                                                 | 人狼陣営か市民陣営のどちらかが勝利した場合に自分自身が生き残っていたときに、別陣営の勝利を取り消して単独で勝利する。 |
| 占い師 | 市民陣営 | 夜の時間にプレイヤーをひとり選んで占い、その役職の陣営を把握できる。しかし、共犯者を占ったときは市民陣営と表示される。                                                 | 人狼陣営が全員死亡すること。                                             |
| 霊媒師 | 市民陣営 | 夜の時間にプレイヤーを一人選び、そのプレイヤーがすでに死んでいた場合、その役職の陣営を把握できる。しかし、それが共犯者であった場合は市民陣営と表示される。                               | 人狼陣営が全員死亡すること。                                             |
| 騎士  | 市民陣営 | 夜の時間にプレイヤーを一人選び、そのプレイヤーを守護する。守護されたプレイヤーは人狼のよって殺されるのに選ばれてもその夜のみ死亡することを回避できる。                                 | 人狼陣営が全員死亡すること。                                             |
